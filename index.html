I am a PhD candidate in Computer Science at the École Normale Supérieure (PSL) and Inria Paris, supervised by Caterina Urban (ENS & Inria).

My research focuses on providing mathematical guarantees about program behavior. I explore the verification of temporal properties of sequential C-like programs. Specifically, I use abstract interpretation to develop static analyses proving CTL properties of programs in adversarial contexts, including termination resilience and vulnerable variable detection.

My PhD topic is Static Analysis by Abstract Interpretation for CTL Properties in Adversarial Contexts.

More broadly, I aim to generalize this branching-time setting (CTL) to Alternating-time Temporal Logic (ATL), which captures what an agent can guarantee against an adversary. This unifies the problems I study — termination resilience and vulnerable variable detection — as strategic temporal properties, all provable within a single sound abstract-interpretation framework for C-like numerical programs.

Open-Source Software

ReFuncTion

Abstract-interpretation-based static analyzer for (conditional) alternating-time temporal properties — including classical termination, non-termination and CTL properties — of C-like numerical programs. Written in OCaml. Extension of FuncTion by Caterina Urban.

GTurbo

A web editor to define a graph rewriting system and apply it to a whole graph at once, based on the framework of global transformations.
